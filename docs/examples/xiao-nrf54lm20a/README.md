# Example: Seeed Studio XIAO nRF54LM20A

`XIAO nRF54LM20A.kisi.json` is a board configuration for kisi: the power tree of the Seeed Studio XIAO
nRF54LM20A (hardware V1.0) for the USB supply case, every value with its source. The board files are by Seeed
Studio (CC BY-SA 4.0) and are not included; where to get them, how the file was made and what is still open is
the worked example in [Preparing a board](../../preparing-a-board.md#worked-example-seeed-studio-xiao-nrf54lm20a).

Copy the file next to `XIAO nRF54LM20A.kicad_pcb` (same stem) and run
`node kisi.mjs config-check "XIAO nRF54LM20A.kicad_pcb"`.
