Cross-sections solved by CST Studio Suite's 2D port-mode solver, by the full-wave (triangular FEM) backend of H. Forstén's js_2d_fields, by kisi's field solver (js_2d_fields' FDM backend, as kisi runs it) and by kisi's closed-form formulas; method and results in validation/cst_xs/README.md. The 3D reference cases (vias, stubs, pairs, plane cavities) are on the page kisi 3D references (a release file next to this one; each is attached to the releases in which its cases changed: releases). · kisi – a side project by David Riehl, started as a visualisation tool for the course Advanced PCB Design at TU Darmstadt; meant to help, without any warranty of correctness.
